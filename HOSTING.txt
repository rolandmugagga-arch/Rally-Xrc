RALLY XRC ON CPANEL PHP HOSTING

Requirements
- PHP 7.4 or newer with pdo_sqlite, mbstring, curl and openssl.
- Apache with .htaccess support, writable site files, and rsync for Git deployment.
- HTTPS and enough storage for the site's database and uploaded media.

Deploy with cPanel Git Version Control
1. In cPanel, open Git Version Control and clone this GitHub repository into a directory OUTSIDE the website document root, such as a new rallyx-deploy directory in your home folder. Do not clone directly into public_html.
2. Set the repository's active branch to main. If the site uses an add-on domain with a document root other than public_html, edit the `DEPLOYPATH="$HOME/public_html"` value in .cpanel.yml to that exact document root.
3. Use cPanel File Manager to copy config.example.php to config.php directly in the site's document root. Edit config.php to uncomment and set a unique administrator email and strong password. Never commit config.php or send its contents to anyone. Do this before the first site visit; the first visit creates the administrator account, and changing these values later does not change an account already created.
4. If the host permits private storage outside the document root, create a writable data directory there and set DB_PATH in config.php to an absolute path ending in rallyx.sqlite. The deployment task preserves config.php, data/, and uploads/files/ on later deployments.
5. In cPanel Git Version Control, choose Deploy HEAD Commit. The included .cpanel.yml syncs the app to the primary domain's public_html by default without deleting other files. Use a dedicated document root for Rally XRC; deploying files with the same names as another site will replace those files. Create config.php before visiting the site.
6. Open check.php on the site and confirm all required checks pass, then delete check.php from the web root.
7. Enable AutoSSL or Let's Encrypt in cPanel. In PHP's MultiPHP INI Editor, raise upload_max_filesize and post_max_size if large videos are needed.
8. Point the domain's DNS to the cPanel host using the host's documented DNS records. The Git deployment does not change DNS.

If Git deployment is unavailable, the files can be uploaded to the domain's document root with cPanel File Manager. Keep config.php, data/, and uploads/files/ intact during updates.

Backups: in Admin, download the database backup regularly, and keep separate copies of uploaded photos and videos.
